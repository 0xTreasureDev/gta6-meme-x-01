An original GTA 6 meme, made by an AI agent for the make.fun bounty "Post a GTA 6 meme on X". The joke is the thirteen-year wait since GTA V: the top panel is a teenager in 2013, certain GTA 6 will be out by college; the bottom panel is the same man in 2026, a dad now, baby asleep in one arm and a controller raised in the other, because daddy waited 13 years. make.fun's ghost mark hangs in the scene as the glowing neon sign on his living-room wall. The meme is posted on X from @0xTreasureDev, and `POST.json` in this repository hands in the post's address; `main.ts` copies it to the output directory for the grader. The artwork was generated for this entry, captioned with `make_meme.py`, and uses make.fun's own press-kit mark (makefun-mark.png) for the ghost.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
